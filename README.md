# Asterwell Hospital concept prototype

This is a client-facing visual prototype with fictional hospital details and a sample appointment flow. It is not connected to a hospital scheduling system and should not be used with real patient information.

Open `index.html` directly to view the browser-ready concept. `preview.html` is the working preview page; both use the same styles, interactions, and local photo assets.

## Run locally

The prototype is plain HTML, CSS, and JavaScript so it opens directly or can be hosted as static files. The existing Vite configuration is available for future app development; this demo does not need a database or a build step.

## Visual assets

The consultation and care-team photos are included in `assets/` so the important visuals load without a network connection. Hospital details, appointment dates, providers, and stories are sample content.
